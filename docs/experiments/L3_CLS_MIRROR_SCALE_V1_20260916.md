Date: 2026-09-16. Status: **prospectively frozen diagnostic readout before fetching detailed mirror payloads**.

## Purpose

The merged CLS master plan requires a mirror-scale diagnostic with a deep Jass reference to bound shared-evaluator bias before any CLS generation is opened. The completed depth/growth diagnostic `cpx62-2000-l3-cls-depth-growth-full-production-v2` showed descriptive Jass/Scan root-decision divergence at the frozen 5k/50k/200k node ladder, but a cross-engine disagreement alone cannot distinguish search-semantic divergence from convergence toward each engine's own evaluator/search fixed point.

This diagnostic therefore measures how the **same current Jass search/evaluator** converges toward a deeper Jass reference on the exact same frozen DEEP512 root cohort. It is `DIAGNOSTIC_ONLY`; it is not a confirmatory claim and it cannot select, fit, promote, bake, tune, or alter any ED/CLS candidate.

## Exact-node semantics

For each DEEP512 parent root, run one fresh Jass search with requested cap 1,000,000 nodes. A searched row is valid only if either:

1. it stops by exact node limit with `nodes_observed == 1,000,000` and an aborted final iteration; or
2. it exhausts complete `MAX_PLY` before the cap with the existing depth-growth exact-cap exception.

No movetime emulation, fixed-depth substitution, warm TT, policy override, model override, root replacement or budget adaptation is allowed.

## Frozen readout

Use JASS_PARITY rows from 2000 at 5k/50k/200k and the new Jass1M parent-root reference. The 2000 Scan rows are reused only as the already-generated external contrast; **no new Scan search is generated by this diagnostic**.

For each budget `b in {5k,50k,200k}` publish:

- `mirror_agreement_b = P(bestmove_JassParity_b == bestmove_JassDeep1M)`;
- `cross_engine_agreement_b = P(bestmove_JassParity_b == bestmove_Scan_b)` from the exact paired 2000 rows;
- `mirror_excess_b = mirror_agreement_b - cross_engine_agreement_b`;
- the same three quantities by phase P0-P3;
- deep-reference completed nominal depth, effective depth, nodes, NPS and root-shape descriptives.

`mirror_excess` is a **bias-bound descriptive contrast**, not a causal estimator. Positive mirror excess is evidence that same-evaluator/same-engine convergence can explain some cross-engine decision divergence; it does not prove that evaluation is the bottleneck. Near-zero or negative mirror excess likewise does not prove search is the bottleneck.

Publish 2.5%, 50%, and 97.5% quantiles for mirror agreement, cross-engine agreement and mirror excess at each budget.

There is no alpha spending, null-hypothesis gate, candidate selection or automatic bottleneck verdict.
