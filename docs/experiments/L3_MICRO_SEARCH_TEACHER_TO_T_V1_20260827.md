## Motivation

Fresh Phase-C established a sharp gap:

- CURRICULUM T pairwise: 0.6094409839
- sealed linear D1: 0.7299377664
- static Rich-D (333→384→192→96→1): 0.7322476093
- q5k search diagnostic: 0.9569280372

Rich-D added only +0.00231 pairwise over D1, with CI crossing zero, while q5k retained ~95.7% agreement with the deep 200k ranking. Capacity/nonlinearity of a static head is therefore not the current bottleneck. The new hypothesis is that the missing information is generated by short lookahead itself.

This protocol tests the minimum node budget needed to recover most of the q5k decision information, confirms that budget on a fresh cohort, and only on confirmation allows distillation into the full production PatternEval sparse representation.

No runtime D/micro-search integration is tested here. The micro-search teacher is offline only.

# Phase M1 — Lookahead budget curve (exploratory, no model fit)

Use exactly the already-frozen Phase-C parent/child identities and q50/q200 stable-pair labels from 1588/1590. Re-run every non-exact sibling from a fresh engine/TT state with byte-identical CURRICULUM, book off, one thread, production search params, exact node-limit mode at the following fixed budgets:

`[125, 250, 500, 1000, 2000, 5000]` nodes per child.

The existing 5k values may be recomputed; recomputation must match the same semantic contract but exact numeric identity is not required if prior code SHA differs only technically. q50/q200 define accepted labels exactly as in DSSD: exact terminal/TB precedence; otherwise sign(d50)==sign(d200), both nonzero, |d50|>=10cp, |d200|>=30cp; target relation is q200.

For every budget publish:

- global pairwise accuracy and top-hit vs deep relation;
- per P0/P1/P2/P3 pairwise;
- per parent colour pairwise;
- parent-cluster bootstrap CI95 for pairwise and top-hit;
- completed/effective depth distributions;
- actual node totals and elapsed wall time;
- fraction of D1 errors fixed, fraction of D1-correct pairs broken;
- overlap/disagreement with q5k;
- PV-enters-EGDB and exact-endgame diagnostics where available.

Let `A_D1` be sealed D1 pairwise on this cohort, `A_5k` the freshly measured/recomputed 5000-node pairwise, and for budget B define recovered headroom:

`H(B) = (A_B - A_D1) / max(1e-12, A_5k - A_D1)`.

Deterministic budget selection rule, fixed before M1 results:

Choose the smallest B in `[125,250,500,1000,2000,5000]` satisfying ALL:

1. global pairwise `A_B >= 0.90`;
2. `H(B) >= 0.85`;
3. pairwise >= 0.87 in every P0/P1/P2/P3;
4. pairwise >= 0.88 for both parent colours.

If no smaller budget qualifies, choose B*=5000 iff 5000 satisfies conditions 1,3,4. If even 5000 fails these distributional conditions, verdict `MICRO_SEARCH_TEACHER_BUDGET_NOT_ESTABLISHED` and stop.

M1 is exploratory by construction; no scientific claim of generalization is permitted from M1.
