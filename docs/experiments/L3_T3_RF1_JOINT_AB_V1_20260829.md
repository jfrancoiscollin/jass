## 1. Scientific questions

Primary transfer question:

> Can the already-confirmed F6 observables be distilled into a fixed T0-residual student that improves q200 sibling ranking on a completely new deep-fresh cohort?

Primary joint question, conditional on F6 transfer:

> Does sealed D1 contain reproducible additive ranking information above the same F6 student when it is supplied as exactly one additional scalar input?

There are exactly two arms. There is no third arm, no post-hoc feature union and no architecture/hyperparameter sweep.

## 2. Arm contracts

### 2.1 Shared score convention

For a sibling child position, let `T0_child` be byte-identical CURRICULUM evaluated from child STM POV. Let the parent be deterministically `opposite(child.stm)`.

Both arms learn a scalar parent-POV residual `r`. The ranking score is

`S(parent, child) = -T0_child + r(child)`.

Equivalently, when a child-evaluator notation is useful, `T3_child = T0_child - r` so that parent ranking is `-T3_child`.

No T0 coefficient is fitted or rescaled. T0 is an immutable base with coefficient exactly `1` in child-evaluator form.

### 2.2 T3-A — `F6_ONLY`

Trainable input is **exactly** the 66 F6 scalars from the frozen Residual Feature Discovery extractor:

`F1_CAPTURE_GEOMETRY || F2_RESPONSE_FRONTIER || F3_PROMOTION_RACE || F4_STRUCTURE_GRAPH || F5_KING_GEOMETRY_PLUS`.

All 66 values retain the preregistered parent-POV definition. They are deterministic, finite and search-free. Full legal move generation and the bounded one-reply enumeration already specified for F2 are permitted; alpha-beta, TT, iterative deepening, node-budget search, learned eval, q-scores and WDL are forbidden inside feature extraction.

T3-A has no D1, T2, q1000/q5k/q50/q200, WDL/outcome, source, partition/split/holdout flag, parent ID or future-holdout statistic as a model input.

### 2.3 T3-B — `JOINT_D1_F6`

T3-B has the exact same 66 F6 inputs plus **one and only one** additional scalar:

- sealed D1 parent-POV sibling score from SHA256 `e91a55500713154f50be74db5d699b64d7684e1c078725d09e1d15e713549b49`.

No D1 refit, rescale, feature expansion or replacement is permitted. T0 is still the same immutable base and is not an input coordinate.

Important interpretation boundary: sealed D1 includes its already-frozen sibling/move-local contract, so T3-B is a **joint sibling-ranking student probe**, not yet proof of a transposition-invariant production leaf evaluator. A B>A PASS establishes additive information and authorizes only a later, separately preregistered runtime/distillation question. It does not authorize search integration here.

## 3. Frozen learner before any new T3 metric

The model is a deterministic single-head residual MLP derived from the already-implemented T2 residual MLP widths, with hard phase routing deliberately removed so phase is not an implicit extra input.

Architecture:

- T3-A: `66 -> 256 -> 128 -> 64 -> 1`;
- T3-B: `67 -> 256 -> 128 -> 64 -> 1`;
- ReLU after the 256, 128 and 64 hidden layers;
- final output linear;
- one shared network across parent colours and phases;
- no bias/output calibration outside the network;
- only input width differs between A and B.

Initialization and optimization are frozen:

- deterministic NumPy Adam;
- shared initialization seed `2026090801`;
- minibatch/order RNG seed `2026090802`;
- deterministic pair-cap ordering seed `2026090803`;
- batch size `4096`;
- exactly `80` epochs, regardless of any intermediate metric;
- learning rate `1e-3`, multiplied by `0.3` after epoch 40 and again after epoch 60;
- weight decay `1e-5` on weight matrices only;
- global gradient-norm clip `5.0`;
- pairwise logistic ranking loss;
- per parent-phase x parent-colour cell cap `150000` pairs, deterministic SHA order using seed `2026090803`;
- every non-empty parent-phase x parent-colour cell has equal total objective weight;
- no early stopping, holdout-driven checkpoint selection, learning-rate selection, L2/weight-decay sweep, width sweep or seed sweep.

Initialization pairing rule: A and B use the same deterministic layer-generation recipe and seed. The common downstream shapes (`256->128->64->1`) are initialized byte-identically. For the first layer, the 66 F6 input rows in B are initialized identically to A; B's one D1 row is initialized deterministically from seed `2026090804`. This nested initialization is fixed before training and is not selected by results.

Normalization:

- fit once from unique TRAIN rows only;
- one mean/std per allowed input coordinate;
- std below `1e-8` is replaced by `1.0`;
- A and B have separate normalization manifests because B has one additional coordinate;
- no q-score, WDL or future-fresh statistic enters normalization.

Artifacts must serialize architecture, feature names/order, normalization, all parameters, optimizer receipt, source attempts and SHA256. Reload must reproduce scores deterministically within a preregistered implementation tolerance fixed before any fresh score is read.
