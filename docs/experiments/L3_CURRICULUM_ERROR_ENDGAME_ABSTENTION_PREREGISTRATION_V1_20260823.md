# CURRICULUM residual: endgame-abstention preregistration

## Discovery and closure

The unconditioned `alpha=300`, `cap=100 cp`, strict-both-change residual is
closed by the negative 1517 fresh confirmation.  Its four catastrophic error
interventions were all endgames, with two present in each independent fresh
pool.  A read-only symmetric counterfactual in 1519a changed the global error,
control and paired means from `-93.804 / +259.764 / -353.568 cp` to
`+196.252 / +8.696 / +187.556 cp`.  Both fresh-pool paired point estimates
became positive.

This phase rule was discovered on 1517.  Those data are not validation and
cannot be reused for any confirmatory decision.

## Single frozen hypothesis

One hypothesis is registered:

- fit the same residual on immutable 1508 only, with `alpha=300`;
- retain the `100 cp` cap, `10 cp` threshold and strict original/image
  consensus;
- when the production piece classifier returns exactly `endgame`, use the
  unmodified CURRICULUM anchor in both orientations and both matched roles;
- in every other phase, replay the frozen residual bit-identically.

There is no threshold sweep, alternate phase boundary or fallback candidate.

## Entirely new confirmation

The confirmation requests exactly 600 fresh matched pairs.  Two new pools of
3,840 openings each use fixed seeds and must be mutually disjoint and disjoint
from the 1492, 1504 and 1515 pools.  The 15,360 resulting CURRICULUM games use
the same byte-identical model on both sides.  Candidate order is frozen before
any exact action target; fresh labels never enter the fit.

All gates are joint: global error and paired 95% lower bounds above zero,
positive error and paired point estimates in each pool, controls at least
`-2 cp` globally and in each pool, minimum intervention counts, symmetry,
positive realisation, zero endgame interventions, bit identity in and outside
the phase gate, and a real paired mean above the 99th percentile of 1,000
shams.

A failure closes this residual family.  A pass authorizes only a separate
strongly anchored local-refit and out-of-sample audit preregistration.  It does
not authorize PatternEval fitting, strength games, frozen reads or promotion.
