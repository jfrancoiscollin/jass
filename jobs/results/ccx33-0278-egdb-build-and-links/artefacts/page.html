International draughts endgame database downloads

You can download install files for the Kingsrow 8-piece WLD and MTC endgame databases using the links below. To use the 8-piece database, you also need to install the database of 2 through 7 pieces. The files are hosted at Mega. For downloading these large files, Mega only supports Chrome and Opera web browsers. More about downloading from Mega.

  • WLD database 2 through 7 pieces
  • WLD 8-piece database, part 1 of 2
  • WLD 8-piece database, part 2 of 2
  • MTC database 2 through 8 pieces

Each install contains a group of .bin files and an .exe setup program file. Download all the files to your PC, then run the setup program to install the database on your hard drive.
